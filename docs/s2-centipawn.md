# S2.0 integer centipawn contract (accepted development candidate)

Baseline: `0a23602e30ec0151200f5b874902b5c49d499e27` (merged PR #55). This explicitly authorized scoring/ABI change passed and was accepted in standard and COMP1 optimized development validation. See [validation results](s2-centipawn-validation.md). PVS is deferred pending integration.

- `chess_eval_abi_v2.h`: ABI major 2, minor 0, signed `int32_t` centipawns in [-1000000,1000000], White-perspective. Snapshot version/layout unchanged. ABI v1 modules must be rejected before evaluation. Errors, invalid output and out-of-range scores are not valid evaluations. Evaluators may compute internally however they choose; output scaling is their responsibility. No optional host calibration API is needed. Metadata requires centipawn units.
- Material module version 2: `pawn_cp=100`, `knight_cp=300`, `bishop_cp=325`, `rook_cp=500`, `queen_cp=900`. Integer weights in [0,16000]; no silent legacy configuration reinterpretation. For example migrate `queen_value: 8` to `queen_cp: 800` explicitly. Sub-centipawn configurations require a deliberate rounding choice. Old persisted registrations may need reconfiguration/re-registration. Do not rewrite historical records.
- SearchScore occupies 4 bytes: finite inclusive +/-1000000; mate base +/-2000001, maximum mate distance 1000000 plies. Mate distance ordering, checked increments and TT normalization are retained. Draw remains zero. SEE and delta use integer centipawns; preserve historical ordering weights/ties rather than changing ordering heuristics. TT budget policy is unchanged.
- UCI `score cp` is side-to-move perspective, while Chess Lab `final_score v2` finite values are White-perspective integer centipawns. Mate fields still encode ply distance. Controller reads historical v1 raw envelopes distinctly, preserves old persisted data and labels native v2 centipawns separately. Generic UCI engines are not granted trusted Chess Lab final-score semantics. GUI may display centipawns as decimal pawn equivalents.
- Validate exact normalized default-material scores, PVs, node counts, mate/draw behavior, deterministic repeated searches, ABI rejection and all existing layers. Compare with exact merged baseline at equal TT entry count and nominal budget; record actual allocation. Standard-build screening and independent fresh COMP1 PGO comparisons passed. Committed-revision Full CI on Windows/WSL (including WASM/controller/GUI) and explicit cross-revision review remain required. Publication and merge require separate authorization.
